# Практическая работа № 5 — Электронный журнал учебных групп

Готовый учебный Django-проект, переделанный с темы автосалона на тему
«Электронный журнал учебных групп». Состав модулей соответствует структуре
практической работы № 5: авторизация, справочники/каталог, учетные записи
обучающихся, журнал, отчеты, REST API и Streamlit-дашборд.

## Состав проекта

- `apps/accounts` — пользователи и роли (администратор, преподаватель, студент), вход и регистрация.
- `apps/clients` — учебные группы и студенты.
- `apps/catalog` — учебные дисциплины и преподаватели.
- `apps/orders` — занятия, оценки и посещаемость.
- `apps/reports` — сводная статистика и успеваемость групп.
- `dashboard/app.py` — отдельный Streamlit-дашборд.
- `config` — настройки Django, маршрутизация.
- `templates` — простые страницы входа, регистрации и главной панели.

## Требования

Python 3.10+, pip. По умолчанию используется SQLite для быстрого первого запуска.
Для работы с PostgreSQL задайте переменные `DB_ENGINE=postgresql`, `DB_NAME`,
`DB_USER`, `DB_PASSWORD`, `DB_HOST` и `DB_PORT` в файле `.env`.

## Установка в Windows PowerShell

Распакуйте архив и откройте его папку в VS Code. В терминале выполните:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
```

## Миграции и запуск Django

```powershell
python manage.py makemigrations accounts clients catalog orders reports
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/admin/` и войдите под учетной записью
суперпользователя. Главная панель доступна после входа по адресу
`http://127.0.0.1:8000/`.

## Заполнение тестовыми данными

Рекомендуемый порядок заполнения через админ-панель:

1. Создайте пользователя-преподавателя, установив роль «Преподаватель».
2. Создайте учебную группу (например, ИС-21).
3. Создайте пользователей-студентов, затем карточки студентов и назначьте им группу.
4. Создайте дисциплины и назначьте преподавателей.
5. Создайте занятия для группы и дисциплины.
6. Добавьте оценки (от 1 до 5) и записи посещаемости.

Для создания оценки студент должен относиться к группе выбранного занятия.
В модели предусмотрена проверка этого правила методом `clean`; при добавлении
через админ-панель Django выполняет валидацию формы модели.

## REST API

Все API-маршруты требуют авторизации. Получить токен можно POST-запросом
на `/api/token/`, передав `username` и `password`.

Основные адреса:
- `/api/clients/study-groups/` — учебные группы.
- `/api/clients/students/` — студенты.
- `/api/catalog/subjects/` — дисциплины.
- `/api/orders/lessons/` — занятия.
- `/api/orders/grades/` — оценки.
- `/api/orders/attendance/` — посещаемость.
- `/api/reports/stats/` — статистика и успеваемость групп.

Пример получения токена через PowerShell:

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/token/ `
  -ContentType "application/x-www-form-urlencoded" `
  -Body "username=ВАШ_ЛОГИН&password=ВАШ_ПАРОЛЬ"
```

## Запуск Streamlit

В отдельном терминале, когда Django-сервер уже запущен:

```powershell
streamlit run dashboard/app.py
```

В поле API-токена вставьте токен, полученный на предыдущем шаге. Для удобства
можно указать `API_TOKEN` в локальном `.env`.
